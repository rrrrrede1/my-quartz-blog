Cloudflare 的电子邮件服务（Email Routing）主要用于**邮件转发**。它可以让你为自己的域名创建无数个自定义邮箱地址（如 `hi@yourdomain.com`），并将收到的邮件自动转发到你常用的个人邮箱（如 Gmail 或 Outlook）。

> 博客的邮箱就是使用该功能 [[aboutme]]  

以下是具体的使用步骤和功能说明：

---

## 1. 基础设置步骤

要使用此功能，你的域名必须已经托管在 Cloudflare 上。

### 第一步：启用服务

1. 登录 Cloudflare 控制台，选择你的域名。
    
2. 在左侧菜单栏点击 **“电子邮件” (Email)**。
    
3. 点击 **“开始使用” (Get Started)**。
    

### 第二步：添加目标地址 (Destination Address)

目标地址是你用来**接收**邮件的真实邮箱。

1. 在“目标地址”页签下，点击 **“添加目标地址”**。
    
2. 输入你的常用邮箱（如 `example@gmail.com`）。
    
3. Cloudflare 会发送一封验证邮件到该地址，点击邮件中的链接完成验证。
    

### 第三步：配置路由规则 (Routing Rules)

1. 在“路由规则”页签下，点击 **“创建地址”**。
    
2. **自定义地址**：输入你想要的名称（如 `admin` 或 `contact`）。
    
3. **目标地址**：选择你刚才验证过的常用邮箱。
    
4. 保存即可。
    

### 第四步：激活 DNS 记录

Cloudflare 会检测你的 DNS 设置。如果尚未配置，系统会提示你添加 **MX 记录**和 **SPF 记录**。

- 点击 **“自动添加”**，Cloudflare 会自动帮你填好这些复杂的解析记录。
    
- **注意**：如果你之前用了其他的企业邮（如腾讯企业邮、飞书邮箱），启用此功能会覆盖掉原有的邮件接收配置。

## 常见问题与限制

|**功能/限制**|**说明**|
|---|---|
|**只能收，不能发**|**核心限制**：该服务原生只支持**接收并转发**。你不能直接用这个界面回复邮件。|
|**如何回复？**|如果需要用域名邮箱回信，通常需要配合 Gmail 的 "Send mail as" 功能，或者使用第三方发送服务（如 Resend, SendGrid, Mailgun）。|
|**附件限制**|转发的邮件大小限制通常为 **25MB**（包含附件）。|
|**免费额度**|该功能目前对所有 Cloudflare 用户**免费**开放。|
